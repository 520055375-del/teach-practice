# teach-practice

小学课堂练习（单文件 HTML）：注意力训练、数位表练习。

## 怎么把页面变成无标识链接

1. 把 `注意力训练-纯净版.html`、`数位表练习-纯净版.html` 拖进本仓库根目录（网页版 Add file → Upload files）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / `root`，保存。
3. 约 1 分钟后，链接形如 `https://520055375-del.github.io/teach-practice/注意力训练-纯净版.html`。

这个链接没有平台生成标识，而且是 https，手机上的语音朗读、语音识别都能用。
